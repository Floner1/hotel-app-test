## Overall risk ranking
- **Critical:** none.
- **High:** none.
- **Medium:** CSP enforced only in report-only mode (inline scripts/handlers block enforcement); default `/admin/` path with no network-level restriction; DB connection privilege level not verifiable from repo (Windows Trusted_Connection or an unscoped SQL login).
- **Low:** asymmetric `IF EXISTS`/`IF NOT EXISTS` guards in two raw-SQL migrations (`0006`, `0007`); file-upload content-type trusted from client header (Pillow decode is the real backstop).
